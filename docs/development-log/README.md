# Development Log

Daily record of work on starter-mygo-react-router. One file per day, `YYYY-MM-DD.md`, newest first.

> Split work that spans days into separate files. Use `##` sections for multiple entries in one day. Move bug patterns discovered here into the [postmortem index](../postmortem/README.md).

## Conventions

- File name `YYYY-MM-DD.md`; first line `# YYYY-MM-DD`.
- Use `## Topic` sections in time order when a day has several changes.
- Each section states what changed, why, the verification commands and results, obstacles, and unfinished work.
- Link decisions to an ADR, postmortem, or review. Link implementation to the commit hash.
- Do not write a diary. Do not present plans as completed. Put unfinished work in the [backlog](../planning/backlog.md) or a `todo-*` file.
- Documents and UI copy follow [writing-style.md](../writing-style.md).
