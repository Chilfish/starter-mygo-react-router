# Support

- Read the [documentation](docs/README.md) first. It covers setup, architecture, code rules, and releasing.
- Search [existing issues](https://github.com/Chilfish/starter-mygo-react-router/issues) before opening a new one.
- Open a bug report or a feature request with the provided issue forms. Include versions and reproduction steps.
- Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
- For questions about MyGo itself, use the [MyGo documentation](https://mygo.egoist.dev/docs) and the [MyGo repository](https://github.com/egoist/mygo).
